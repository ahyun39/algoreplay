# SQL 서브쿼리와 WITH

## 1. 핵심 개념
쿼리 결과를 다른 쿼리의 값·조건·테이블로 다시 쓴다. `WITH 이름 AS (…)`(CTE)는 단계를 이름 붙여 나눈다.

## 2. 동작 원리
스칼라 서브쿼리는 값 하나, `IN`/`EXISTS` 서브쿼리는 조건, `FROM` 안의 서브쿼리와 CTE는 임시 테이블처럼 쓰인다.

## 3. 시간복잡도
바깥 행마다 다시 계산되는 상관 서브쿼리는 O(N·M)이 될 수 있다. 조인이나 미리 집계한 CTE로 바꾸면 빨라진다.

## 4. SQL에서
`WITH t AS (SELECT user_id, COUNT(*) c FROM log GROUP BY user_id) SELECT … FROM users LEFT JOIN t USING (user_id)`

## 5. 언제 사용하는가
집계 결과로 다시 필터할 때, 윈도우 함수 결과로 거를 때, 복잡한 문제를 단계별로 나눌 때.

## 6. 자주 하는 실수
- `NOT IN (서브쿼리)`에 `NULL`이 섞이면 결과가 비어 버림 (`NOT EXISTS` 권장)
- 스칼라 서브쿼리가 두 행 이상을 돌려줌

## 7. 연습 질문
"모든 상품을 산 고객"을 집계 한 번과 서브쿼리 한 번으로 표현해 보자.
