# Binary Search (이분 탐색)

## 1. 핵심 개념
정렬되었거나 단조성이 있는 구간에서 탐색 범위를 매번 절반으로 줄인다.

## 2. 동작 원리
불변식을 정한다: 답은 항상 [lo, hi] 안에 있다. mid를 검사해 한쪽 절반을 버린다. 답 자체를 탐색하는 '매개 변수 탐색'도 같은 원리다.

## 3. 시간복잡도
O(log N). 매개 변수 탐색은 O(log 범위 × 판정 비용).

## 4. Python에서
`bisect.bisect_left / bisect_right`를 활용할 수 있다.

## 5. 언제 사용하는가
정렬된 배열 탐색, '조건을 만족하는 최소/최대값' 찾기.

## 6. 자주 하는 실수
- `lo < hi`와 `lo <= hi` 혼용 (boundary condition)
- `hi = mid`와 `hi = mid - 1` 혼동으로 무한 루프
- 단조성이 없는데 적용
