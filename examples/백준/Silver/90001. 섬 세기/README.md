### 문제 설명

<p>N×M 격자 지도에서 <code>1</code>은 땅, <code>0</code>은 바다이다. 상하좌우로 이어진 땅은 하나의 섬이다.</p>

<p>섬의 개수와 가장 큰 섬의 넓이를 구하시오. 예를 들어 지도가 다음과 같다면</p>

<pre>1100
0100
0011</pre>

<p>섬은 2개이고 가장 큰 섬의 넓이는 3이다.</p>

### 입력 

 <p>첫째 줄에 N과 M이 주어진다. (1 ≤ N, M ≤ 500)</p>

<p>둘째 줄부터 N개 줄에 길이 M의 0과 1로 이루어진 문자열이 주어진다.</p>

### 출력 

 <p>섬의 개수와 가장 큰 섬의 넓이를 공백으로 구분해 출력한다. 섬이 없으면 <code>0 0</code>을 출력한다.</p>
