# Implementation / Simulation

## 1. 핵심 개념
문제에서 설명한 과정을 그대로 코드로 옮긴다. 알고리즘보다 정확한 구현이 핵심이다.

## 2. 동작 원리
상태(좌표, 방향, 시간)를 정하고 규칙을 순서대로 적용한다. 규칙마다 함수로 나누면 디버깅이 쉽다.

## 3. 시간복잡도
규칙 적용 횟수 × 한 번의 비용.

## 4. Python에서
방향 배열 `dirs = [(-1,0),(0,1),(1,0),(0,-1)]`, 회전은 `(d + 1) % 4`.

## 5. 언제 사용하는가
시뮬레이션, 문자열 가공, 좌표 이동.

## 6. 자주 하는 실수
- 규칙 적용 순서 오류
- 동시에 일어나야 할 변화를 순차 적용
- 경계 조건 누락
