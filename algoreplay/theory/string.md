# String

## 1. 핵심 개념
문자열 탐색, 변환, 파싱.

## 2. 동작 원리
문자 단위 순회, 슬라이싱, 분할/결합. 문자열은 불변이라 수정마다 새 문자열이 생긴다.

## 3. 시간복잡도
`s + t`, `replace`, `in`은 길이에 비례(O(N)).

## 4. Python에서
반복문에서 `+=`로 이어 붙이기보다 리스트에 모은 뒤 `''.join`이 빠르다.

## 5. 언제 사용하는가
팰린드롬, 문자 빈도, 파싱, 패턴 찾기.

## 6. 자주 하는 실수
- 반복문 안에서 replace/슬라이싱을 반복해 O(N^2)
- 입력 끝 개행 문자 처리 누락

## 7. 연습 질문
