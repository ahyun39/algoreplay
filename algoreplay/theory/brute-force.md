# Brute Force (완전 탐색)

## 1. 핵심 개념
가능한 모든 경우를 확인한다. 가장 확실하지만 입력 크기가 작을 때만 가능하다.

## 2. 동작 원리
중첩 반복, `itertools.permutations / combinations / product`, 비트마스크로 모든 경우를 만든다.

## 3. 시간복잡도
경우의 수 × 경우당 확인 비용. N ≤ 10 정도면 N!, N ≤ 20이면 2^N이 가능하다.

## 4. Python에서
`itertools`로 경우를 생성하면 코드가 짧고 실수가 적다.

## 5. 언제 사용하는가
입력 제한이 작을 때, 또는 더 빠른 풀이를 검증할 기준 답이 필요할 때.

## 6. 자주 하는 실수
- 입력 크기로 허용 복잡도를 먼저 계산하지 않음
- 중복 경우를 세어 버림
