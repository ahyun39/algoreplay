# Backtracking

## 1. 핵심 개념
해를 한 단계씩 만들어 가다가 조건을 만족할 수 없으면 즉시 되돌아간다(가지치기).

## 2. 동작 원리
선택 → 재귀 → 선택 취소. 불가능한 분기를 일찍 끊을수록 빨라진다.

## 3. 시간복잡도
최악은 완전 탐색과 같지만 가지치기로 크게 줄어든다.

## 4. Python에서
상태를 전역 리스트로 두면 선택 취소(pop)를 잊지 않도록 주의한다.

## 5. 언제 사용하는가
N-Queen, 순열/조합 생성, 스도쿠.

## 6. 자주 하는 실수
- 선택 취소 누락
- 가지치기 조건을 재귀 호출 후에 검사

## 7. 연습 질문
가지치기 조건을 재귀 호출 전에 검사하면 무엇이 달라지는가?
