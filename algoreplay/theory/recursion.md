# Recursion / 분할 정복

## 1. 핵심 개념
문제를 같은 형태의 더 작은 문제로 나눠 자기 자신을 호출한다.

## 2. 동작 원리
종료 조건 → 더 작은 문제 호출 → 결과 결합. 분할 정복은 절반씩 나눠 합친다.

## 3. 시간복잡도
호출 횟수 × 호출당 비용. 호출이 두 갈래로 겹치면 O(2^N)이 될 수 있다(→ 메모이제이션).

## 4. Python에서
재귀 한도 1000. `sys.setrecursionlimit`로 늘릴 수 있지만 깊이 자체를 줄이는 것이 우선이다.

## 5. 언제 사용하는가
하노이 탑, 거듭제곱, 병합 정렬, 트리 순회.

## 6. 자주 하는 실수
- 종료 조건 누락
- 같은 부분 문제를 반복 계산
- 재귀 한도 초과
