# DFS (깊이 우선 탐색)

## 1. 핵심 개념
한 방향으로 끝까지 들어간 뒤 되돌아오며 탐색한다. 연결 요소, 경로 존재 여부, 사이클 판별에 쓴다.

## 2. 동작 원리
재귀 또는 스택으로 구현한다. 방문 표시 후 방문하지 않은 이웃으로 재귀 호출한다.

## 3. 시간복잡도
O(V + E).

## 4. Python에서
Python 기본 재귀 한도는 1000이다. 깊은 재귀는 `sys.setrecursionlimit`이 필요하고, 그래도 스택이 넘칠 수 있어 명시적 스택이 안전하다.

## 5. 언제 사용하는가
연결 요소 개수, 트리 순회, 백트래킹의 뼈대, 위상 정렬.

## 6. 자주 하는 실수
- 재귀 한도 초과(RecursionError)
- 방문 표시 시점 오류로 무한 재귀
- 전역 상태를 되돌리지 않음

## 7. 연습 질문
재귀 DFS를 명시적 스택으로 바꿀 때 방문 순서를 같게 유지하려면 무엇을 주의해야 할까?
