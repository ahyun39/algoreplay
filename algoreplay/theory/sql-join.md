# SQL JOIN

## 1. 핵심 개념
두 테이블의 행을 연결 조건(`ON`)으로 이어 붙여 한 행으로 만든다.

## 2. 동작 원리
`INNER JOIN`은 양쪽에 짝이 있는 행만, `LEFT JOIN`은 왼쪽 행을 모두 남기고 짝이 없으면 오른쪽 열을 `NULL`로 채운다. 같은 테이블을 별칭 두 개로 이으면(self join) 행끼리 비교할 수 있다.

## 3. 시간복잡도
DB가 해시 조인·정렬 병합 조인·인덱스 조인 중에서 고른다. 연결 키에 인덱스가 없으면 큰 테이블끼리의 조인은 느려진다.

## 4. SQL에서
`SELECT … FROM A LEFT JOIN B ON A.id = B.a_id`. 없는 짝을 찾을 때는 `LEFT JOIN … WHERE B.a_id IS NULL`.

## 5. 언제 사용하는가
정보가 여러 테이블에 나뉘어 있을 때, "~가 없는" 행을 찾을 때, 같은 테이블의 다른 행(관리자-직원, 어제-오늘)과 비교할 때.

## 6. 자주 하는 실수
- `LEFT JOIN` 뒤 `WHERE`에 오른쪽 열 조건을 걸어 사실상 `INNER JOIN`이 됨 (조건은 `ON`에)
- 1:N 조인 후 집계해서 값이 중복으로 커짐
