# Prefix Sum (누적 합)

## 1. 핵심 개념
앞에서부터의 합을 미리 저장해 구간 합을 O(1)에 구한다.

## 2. 동작 원리
S[i] = a[0] + … + a[i-1], 구간 [l, r) 합 = S[r] - S[l]. 2차원도 같은 원리.

## 3. 시간복잡도
전처리 O(N), 질의 O(1).

## 4. Python에서
`itertools.accumulate`를 쓸 수 있다. 앞에 0을 하나 두면 경계 처리가 쉽다.

## 5. 언제 사용하는가
구간 합 질의가 여러 번 들어올 때.

## 6. 자주 하는 실수
- 인덱스를 1칸 밀지 않아 경계 오류
- 질의마다 다시 합산
