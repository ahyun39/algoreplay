# Union-Find (분리 집합)

## 1. 핵심 개념
원소들이 어떤 집합에 속하는지를 빠르게 합치고 확인한다.

## 2. 동작 원리
find: 대표 원소를 찾으며 경로 압축. union: 대표끼리 연결(랭크/크기 기준).

## 3. 시간복잡도
거의 O(1) (아커만 역함수).

## 4. Python에서
재귀 find는 깊어질 수 있어 반복문 + 경로 압축이 안전하다.

## 5. 언제 사용하는가
연결 여부 질의, 사이클 판별, 크루스칼 MST.

## 6. 자주 하는 실수
- 경로 압축 누락으로 시간 초과
- parent[x]를 find(x) 대신 직접 비교

## 7. 연습 질문
union 순서를 무작위로 하면 트리 높이는 어떻게 되는가?
