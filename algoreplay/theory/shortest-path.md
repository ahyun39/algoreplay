# Shortest Path

## 1. 핵심 개념
가중 그래프에서 최소 비용 경로를 구한다.

## 2. 동작 원리
데이크스트라: 음수 간선이 없을 때 힙으로 가장 가까운 정점을 확정. 벨만-포드: 음수 간선 허용. 플로이드-워셜: 모든 쌍.

## 3. 시간복잡도
데이크스트라 O(E log V), 벨만-포드 O(VE), 플로이드 O(V^3).

## 4. Python에서
`heapq`에 (거리, 정점)을 넣고, 꺼낸 거리가 저장된 거리보다 크면 건너뛴다.

## 5. 언제 사용하는가
가중치가 있는 최단 거리. 가중치가 모두 같으면 BFS로 충분하다.

## 6. 자주 하는 실수
- 오래된 힙 원소를 건너뛰지 않아 시간 초과
- 음수 간선에 데이크스트라 사용
- INF 값이 너무 작음

## 7. 연습 질문
