# Dynamic Programming

## 1. 핵심 개념
큰 문제를 겹치는 작은 부분 문제로 나누고, 부분 문제의 답을 저장해 재사용한다.

## 2. 동작 원리
① 상태 정의(dp[i]가 무엇인지) ② 점화식 ③ 초기값 ④ 계산 순서(bottom-up) 또는 메모이제이션(top-down).

## 3. 시간복잡도
상태 수 × 상태당 전이 비용.

## 4. Python에서
`functools.lru_cache`로 top-down 메모이제이션을 쉽게 쓸 수 있다. 재귀 깊이에 주의한다.

## 5. 언제 사용하는가
최적값/경우의 수를 묻고, 같은 부분 문제가 반복해서 등장할 때.

## 6. 자주 하는 실수
- 상태 정의가 모호해 점화식이 틀어짐
- 초기값/인덱스 0 처리 누락
- 모듈러 연산을 중간에 빼먹음
