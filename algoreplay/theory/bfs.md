# BFS (너비 우선 탐색)

## 1. 핵심 개념
시작점에서 가까운 정점부터 차례로 방문한다. 간선 가중치가 모두 같을 때 최단 거리를 구한다.

## 2. 동작 원리
큐에 시작점을 넣고 방문 표시 → 꺼낸 정점의 이웃 중 방문하지 않은 정점을 방문 표시 후 큐에 넣기를 반복한다.

## 3. 시간복잡도
O(V + E). 격자 N×M에서는 O(NM).

## 4. Python에서
`collections.deque`의 `append` / `popleft`는 O(1). `list.pop(0)`은 O(N)이라 피한다.

## 5. 언제 사용하는가
최단 이동 횟수, 격자에서 영역/거리 계산, 레벨 단위 탐색.

## 6. 자주 하는 실수
- 큐에서 꺼낼 때가 아니라 넣을 때 방문 표시하지 않아 같은 칸이 여러 번 들어감
- 격자 경계 검사 누락
- 여러 시작점이 있을 때 한 번에 큐에 넣지 않음(멀티 소스 BFS)

## 7. 연습 질문
가중치가 0과 1뿐인 그래프에서 최단 거리를 구하려면 BFS를 어떻게 바꿔야 할까? (0-1 BFS)
