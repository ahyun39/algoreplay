# Complexity

## 1. 핵심 개념
시간복잡도는 입력 크기 N에 따른 연산 수 증가율, 공간복잡도는 추가 메모리 증가율이다.

## 2. 동작 원리
가장 깊은 반복 중첩, 반복 안의 숨은 선형 연산(`in list`, `replace`, `sum`), 재귀 호출 수를 본다.

## 3. 시간복잡도
대략 1초에 1억 번 이하의 단순 연산(Python은 그보다 느림). N ≤ 10^5면 O(N log N), N ≤ 10^3이면 O(N^2)까지.

## 4. Python에서
측정된 실행 시간은 환경에 의존한다. 이론적 복잡도와 측정값을 구분한다.

## 5. 언제 사용하는가
풀이를 쓰기 전에 입력 제한으로 허용 복잡도를 먼저 정한다.

## 6. 자주 하는 실수
- 반복문 안의 O(N) 연산을 놓침
- 실행 시간이 짧으면 복잡도도 좋다고 착각

## 7. 연습 질문
추가 메모리를 써서 시간을 줄이는 선택(time-space trade-off)을 한 적이 있는가?
