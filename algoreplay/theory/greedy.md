# Greedy (탐욕법)

## 1. 핵심 개념
매 순간 지금 가장 좋아 보이는 선택을 하고 되돌리지 않는다.

## 2. 동작 원리
보통 정렬 후 하나씩 선택한다. 선택이 전체 최적을 해치지 않는다는 근거(교환 논증)가 필요하다.

## 3. 시간복잡도
대개 정렬 O(N log N) + 선형 순회 O(N).

## 4. Python에서
`sorted(key=...)`로 선택 기준을 명확히 표현한다.

## 5. 언제 사용하는가
회의실 배정, 거스름돈(특정 화폐 단위), 구간 선택처럼 국소 선택이 최적임을 보일 수 있을 때.

## 6. 자주 하는 실수
- 반례를 확인하지 않고 탐욕 선택을 적용
- 정렬 기준의 2차 키를 빠뜨림
