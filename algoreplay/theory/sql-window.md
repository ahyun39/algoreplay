# SQL 윈도우 함수 (OVER)

## 1. 핵심 개념
행을 묶어 없애지 않고, 각 행 옆에 "자기 묶음 안에서의" 순위·누적합·이전 값을 붙인다.

## 2. 동작 원리
`함수() OVER (PARTITION BY 그룹 ORDER BY 기준)`. `PARTITION BY`는 묶음을, `ORDER BY`는 묶음 안의 순서를 정한다.

## 3. 시간복잡도
파티션별 정렬이 필요해 대략 O(N log N).

## 4. SQL에서
- 순위: `ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`
- 이전/다음 행: `LAG(col)`, `LEAD(col)`
- 누적: `SUM(col) OVER (ORDER BY …)`

## 5. 언제 사용하는가
그룹별 상위 N개, 연속된 값 찾기, 전날 대비 비교, 누적 합계가 기준을 넘는 지점.

## 6. 자주 하는 실수
- 윈도우 결과를 같은 `SELECT`의 `WHERE`에서 바로 쓰려 함 (서브쿼리/`WITH`로 감싸야 함)
- 동점 처리 차이(`RANK` 1,1,3 vs `DENSE_RANK` 1,1,2)를 놓침
